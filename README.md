# Soenneker.GeoNames.Cities500.Data

GeoNames cities500 data for cities with population greater than 500 or administrative seats, updated daily.

## Install

```bash
dotnet add package Soenneker.GeoNames.Cities500.Data
```

## What it provides

- GeoNames cities500 data for cities with population greater than 500 or administrative seats, updated daily.

## How to use it

Install the package, then consume the supplied build or runtime asset from your application. No service registration is required because this package exposes content rather than a callable API.
